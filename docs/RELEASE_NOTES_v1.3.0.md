# ChatInsight v1.3.0

## 修复

- 修复 NSIS 覆盖更新时旧卸载器删除应用同级 `data` 目录，导致隐私密码、恢复码包装信息和加密 API 凭据丢失的问题。
- 安装器现在会在卸载旧版本前将整个加密数据目录原子移动到安装目录之外，并在新版本文件落盘后原子恢复。
- 新安装器与旧版本安装器兼容：升级 v1.2.0 时由 v1.3.0 安装器主动保护数据，不依赖旧卸载器自身修复。
- 应用启动时会检测中断更新留下的安全备份，在不存在冲突时自动恢复；若现有数据与备份同时存在，则停止启动并显示两个路径，绝不静默合并或覆盖。
- 覆盖更新不允许在存在旧数据时更换安装目录，安装器会明确停止并保留原目录。

## 升级说明

- 关闭正在运行的 ChatInsight 后，使用 v1.3.0 安装包覆盖安装到 v1.2.0 的同一目录。
- 原有应用密码、恢复码、模型服务 API 密钥、聊天记录、图片、人设、风格和分析历史会原样保留。
- 若安装过程被中断，请根据安装器显示的数据备份路径重新运行安装器；不要手工合并 `vault.db` 文件。
- 正在运行的旧版本无法防止此前版本安装器的破坏性目录重建；本修复从 v1.3.0 安装器起生效，并支持从 v1.2.0 直接升级。

## 验证

- 单元测试覆盖无备份、完整恢复、空目录恢复、双份数据冲突和非目录备份。
- Windows 覆盖安装测试覆盖 v1.2.0 建库并保存模拟 API 凭据、升级到 v1.3.0、原密码解锁和凭据保留。
