# ChatInsight v1.3.1

## 新增

- 聊天记录分析页面新增可选的“补充问题”输入框，最多 2000 字。
- 补充问题会与所选分析模式的默认分析一并发送给同一模型请求，并独立展示“默认问题分析”和“补充提问回答”。
- 补充回答包含问题原文、回答正文、证据引用和不确定性说明，并随分析历史加密保存。
- Markdown 与 JSON 导出包含补充问题和补充回答；历史报告继续兼容没有补充问题的旧结果。

## 异常处理

- 补充问题留空时保持原有分析流程、请求结构和结果格式不变。
- 补充问题输入有长度限制，分析预检会展示即将发送的问题。
- 请求执行期间禁用重复提交，仍可在分析过程中取消。
- 模型漏答、补充回答为空或结构无效时，仅将补充部分标记为失败并提示重试，不会丢弃已通过校验的默认分析结果。
- 补充问题被明确隔离为待分析数据，不能覆盖系统安全边界。

## 覆盖安装与数据安全

- 继续使用 v1.3.0 引入的 NSIS 原子备份与恢复策略，覆盖安装前不会删除应用同级 `data` 目录。
- 安装器仍在数据目录与更新备份发生冲突时停止，不合并、不覆盖 `vault.db`。
- 应用启动继续支持中断更新恢复，并对双份数据冲突拒绝自动处理。
- 本版本没有数据库结构变更，不需要迁移已有保险库；v1.3.0 可直接覆盖安装到 v1.3.1。
- 自动化覆盖升级验证覆盖已导入聊天消息、隐私密码、恢复码包装和加密 API 凭据。

## 验证

- TypeScript 严格类型检查。
- 单元测试覆盖补充问题边界、旧结果兼容和补充回答 schema。
- Electron E2E 覆盖有效补充回答、模型漏答时的默认结果保留、结果展示和历史回看。
- 真实 NSIS 覆盖升级测试覆盖 v1.3.0 → v1.3.1 的数据、隐私密码、恢复码和凭据保留。

## 升级说明

- 关闭正在运行的 ChatInsight，使用 v1.3.1 安装包覆盖安装到 v1.3.0 的同一目录。
- 覆盖更新存在旧保险库时不能更换安装目录。
- 若安装过程被中断，请按安装器提示保留更新备份并重新运行安装器。
