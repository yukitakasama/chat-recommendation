# ChatInsight v1.3.4

## 新增

- 模型服务配置新增“最大输入 tokens”和“最大输出 tokens”，用户可按模型与中转站能力自由调整。
- 新配置默认最大输入 350000 tokens、最大输出 200000 tokens。
- 模型服务列表和每次分析预检都会显示当前输入预算、估算输入量与输出上限。
- 主分析请求使用配置的最大输出预算，不再受固定 6000 tokens 或 24000 tokens 上限限制。
- 输入超过配置上限时，应用会在发起网络请求前停止并提示估算值、当前上限与调整方式。
- Responses 与 Chat Completions 请求超时默认调整为 10 分钟，避免大输入或大输出请求过早超时。

## 数据与兼容

- 现有模型服务通过数据库迁移自动获得 350000 / 200000 默认值，无需重新配置。
- API 密钥、聊天记录、保险库密码、恢复码和分析历史不会因迁移被覆盖或删除。
- 辅助摘要、风格提取和截图识别仍可使用各自较小的单次预算；最终综合分析使用用户设置的最大输出预算。

## 使用说明

- 默认值不代表所有模型都实际支持，请以中转站和模型声明的上下文窗口、最大输出为准。
- 输入 token 数采用本地保守估算：非 ASCII 字符按字符计，ASCII 文本按约四字符一个 token 计，图片每张另按 1500 tokens 估算。
- 提高输入或输出上限可能增加请求耗时和模型服务费用。

## 验证

- 单元测试覆盖配置 schema、旧数据库迁移、输入超限拦截、输出预算钳制和 Responses 流式请求。
- TypeScript 严格类型检查、完整单元测试与 Electron E2E。
- 真实 NSIS 覆盖升级测试覆盖 v1.3.3 → v1.3.4 的已导入消息、隐私密码、恢复码和加密 API 凭据保留。

## 升级说明

- 关闭正在运行的 ChatInsight，使用 v1.3.4 安装包覆盖安装到 v1.3.3 的同一目录。
- 覆盖更新存在旧保险库时不能更换安装目录。
